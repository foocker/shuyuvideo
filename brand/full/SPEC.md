# 数语 · 连续文字版品牌片头

用户确认前 3 秒可用，完整版只保留“探索理性与想象的边界”，并要求文字本身有动画、解决前后割裂。

本版 7 秒、1920×1080、30 fps，共 210 帧。前 0–3 秒与批准的短版完全一致。同一个 Ω 和“数语”全程保留在同一场景，3 秒后上移 100 px、缩至 0.88 倍，为一句话留空间。没有换幕、淡出品牌或第二套几何插图。

| 时间 | 文字与主体动作 |
| --- | --- |
| 0–3 秒 | 原版 Ω 成形、睁眼、名称、眨眼与定格 |
| 3.00–3.72 秒 | Ω 和数语同步上移，空间连续 |
| 3.40–3.86 秒 | “探索”从左下轻轻进入 |
| 3.60–4.07 秒 | “理性”以均匀速度从左向右展开 |
| 3.92–4.20 秒 | “与”接续 |
| 4.04–4.78 秒 | “想”“象”略带不同高度与倾角，舒展到同一基线 |
| 4.20–4.50 秒 | “的”出现 |
| 4.31–4.84 秒 | “边”“界”从两侧归位，整句完成 |
| 4.84–7.00 秒 | 完整品牌与宣言静止，持续 2.16 秒 |

文案 58 px、深绿，与既有字形一致。品牌色与短版相同。Ω 仅在文字出现时轻微向下看，再看回观众。无独立几何图形、无“让更多人认识数学，参与数学”。

`continuation.html` 和 `continuation.js` 是延续部分的编辑源；构建脚本将它们合并到短版同一暂停 GSAP 时间线，输出 `compositions/intro.html`。不要直接编辑生成文件。

验收：3 秒前逐帧与短版匹配；2.95/3.00/3.10 秒主体无跳切；完整一句在 4.84 秒归位；6.0 与 6.967 秒画面相同；手机宽度仍清楚可读。
