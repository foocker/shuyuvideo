# 数语 Ω 角色基础库

目标是可复用的角色资产与动作系统。参考 ../../../shuyuvideostudy/pi.png 的平面符号角色：眼睛在符号顶部，笔画是身体，动作通过身体变形、眼神和肢体配合完成。

字形来源：../../../ShuYu2/src/app/icon.svg 采用 Georgia 的大写 Ω。提取本机 Georgia 的 Ω 矢量轮廓，按 300 单位高归一化，保留拱形、底部缺口和两端的辨识度。不把 Ω 换成圆形人偶，也不在符号下方再添两根无关的腿。下方两个笔画末端就是脚，可独立抬起；两侧细手臂连接到字形外侧。手是同色的掌、拇指与三根圆指，支持张手、握拳、指向。

基础配色为网站的墨色 #141413、纸色 #eaeae2、陶土色 #cc5a36；另提供参考图的蓝色预设。默认墨色角色。眼白为 #fffdf6，瞳孔为 #141413；眼睛带细轮廓，在浅色背景上也清楚。嘴位于 Ω 顶端笔画上，随角色颜色切换对比色。

局部坐标以脚底 y=0 为地面。眼睛中心约 (±37,−318)，左右独立眼睑。目光始终限制在眼白内。脚部变形权重只作用于字形下部；站立、挥手、指向、讲解时脚底不因呼吸或歪头漂移。行走提供原地与移动模式，移动模式的支撑脚在地面保持固定。

动作至少覆盖待机、眨眼、看向、挥手、左右指向、讲解、思考、点头、摇头、摊手、跳跃、行走、鞠躬和庆祝。表情与动作可独立组合。所有状态按绝对时间计算，可随机拖动、复现、导出透明素材；动作先蓄势，再运动，再停留和收回。播放控制留在预览页，角色库本身不用时钟或请求动画帧。

交付为可直接打开的 study.html、零运行时依赖的 SVG 角色库、HyperFrames 36 秒动作预览、当前姿态透明 SVG/PNG 导出、透明 WebM 动作导出脚本及示例。独立动作库与展示视频静音，方便接入后续数学视频。

验收：每个动作主姿态、眨眼闭合帧、手脚连接、脚底约束、移动行走支撑脚、Ω 底部开口、随机跳转、双实例不串扰、透明通道，以及实际导出文件。此版是正面与少量侧倾的二维角色，不包含三维背身转身。
