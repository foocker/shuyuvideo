# 角色与动作约定

橙色 `#FF8808`，圆线帽，13 单位线宽，空心头半径 42 单位。站立约 262 单位高；无五官、手掌、鞋子、衣服。轮廓由一条躯干、四条连续肢体和一个空心头组成，柔化肘膝折点。

坐标：x 向右，y 向下，脚底中心线 y=0；身体根平移 `root` 单独存放。动作默认朝右，`mirror` 可反向。`head/neck/waist/hip` 与肘、手、膝、脚均可编辑。`headScale` 和 `headTilt` 只做轻微头形与倾角变化。每次求值只依赖动作、绝对时间和选项。

走跑使用归一化步幅、接触相与双骨 IK。行进模式中支撑脚的世界坐标固定；原地模式是一种跑步机视图，地面不跟随。拾取保持前脚固定，按压保留脚与手的接触保持段，悬挂保持双手固定。不同动作切换使用 `blend` 或明确剪切，不承诺跨任意动作自动足底锁定。

不采用：正弦波全身摇摆代替行动、给无五官角色加眼睛、用镜头运动掩盖滑步、自动伪造原片骨架、把补画动作说成精确逐帧复刻。

## 48 秒展示

| 时间 | 动作 | 读取重点 |
|---|---|---|
| 0–3 | observe | 低头，停住，再收回 |
| 3–7 | walk | 交替迈步 |
| 7–11 | run | 前倾、腾空与落地 |
| 11–17.4 | pick | 接触点与拾取后的手部随动 |
| 17.4–22.2 | press | 接触后的压重 |
| 22.2–26 | drag | 低姿牵引、另一只手保持平衡 |
| 26–30.5 | hang | 双手不漂移，腿部跟随 |
| 30.5–36 | recover | 坐起后停顿，收腿再起身 |
| 36–40 | jump | 蓄力、摆臂离地、空中收腿、缓冲站稳 |
| 40–44 | frontflip | 前转收腿、倒置、展开、落地 |
| 44–48 | backflip | 抬胸后转、收腿倒置、展开、落地 |

这是可检索动作目录，片段间使用明确切换，每段开头保留 0.25 秒读取；不是连贯故事。背景 `#11171C`，角色展示位 x=640、脚线 y=835、缩放 1.95；右侧动作名 60px、说明 30px。

腾空段使用缩放 1.75 留出上方空间。jump 腾空 0.58–1.46 秒、高度 96 单位；frontflip/backflip 腾空 0.58–1.62 秒、高度 146/154。空翻围绕身体重心的转角关键帧覆盖 ±360°；肢体同时收缩/展开，不把站姿整体匀速旋转一圈。可选行进分别为 +150、+220、−175 单位，落地后的位移固定。
