# 墨影 v3 动作目录分镜

117.5 秒，1920×1080，30fps，静音。通常前 0.25 秒停在初态，开枪为 0.08 秒；单次动作在末态停稳，循环动作按自身周期。基础动作右侧是火柴人；新增动作右侧是三个墨影关键姿态。

| 时间 | 动作 | 可见动作 / 影片用途 |
| --- | --- | --- |
| 0–3s | 站立 · 低头观察 | 先偏头注意地面，再停住观察。  |
| 3–7s | 行走循环 | 小幅摆臂，身体向前经过支撑脚。  |
| 7–11s | 奔跑循环 | 前倾、屈臂、腾空，再压低重心着地。  |
| 11–17.4s | 蹲下 · 拾取 · 端详 | 看见地上的点，蹲下碰到它，拿起端详，再伸出去。  |
| 17.4–22.2s | 蹲姿按压 | 蹲姿伸手，重心压向接触点，再收回。  |
| 22.2–26s | 低姿拖拽 | 低姿抓住地面物体，另一只手向后展开保持平衡。  |
| 26–30.5s | 双手悬挂 | 抓点保持固定，身体和双腿在下方摆动。  |
| 30.5–36s | 躺下 · 坐起 · 站立 | 坐起后留一拍观察，收腿、前移重心，再站直。  |
| 36–40s | 跳跃 · 落地缓冲 | 下蹲蓄力，摆臂离地，收腿腾空，落地屈膝再站稳。  |
| 40–44s | 前空翻 | 蹬地前翻，收腿绕过倒置姿态，提前打开身体，双脚落地。  |
| 44–48s | 后空翻 | 向上蹬地，抬胸后翻，收腿越过头顶，打开后落地。  |
| 48–52s | 接过论文 | 先看纸页，双手接住，再抬到眼前。 11、12、14、15：纸页、论文与手稿 |
| 52–56s | 持纸阅读 | 双手托住纸页，目光按行移动。 12、14、15：阅读论文和书信 |
| 56–60s | 翻阅一页 | 一手托纸，一手捏起页角翻过去，再扶稳。 14、15、35：手稿整理与翻阅 |
| 60–64s | 递出论文 | 把文稿递向前方，留出交接停顿后松手。 13、15、35：收稿与接续 |
| 64–69s | 迎风护稿 | 察觉风起，抱紧纸页下蹲，压住后重新站稳。 11、13、17：风雪护纸与扑住手稿 |
| 69–72s | 举枪 | 目光先锁定，前臂抬起，身体稳住。 按用户新增：独立持枪动作；不自动改变第16镜 |
| 72–73.5s | 持枪瞄准 | 脚底固定，胸口和手臂只有克制的呼吸。 用户指定的持枪动作 |
| 73.5–75.5s | 开枪与回弹 | 短暂稳枪后立即击发，手腕后坐，躯干吸收，再回到瞄准。 用户指定的开枪动作；单次、无目标和伤口 |
| 75.5–78.5s | 收枪放低 | 停留确认后放低枪口，肩膀随后松开。 用户指定持枪动作的结束态 |
| 78.5–82.5s | 失衡后倒 | 胸口先失衡，脚离地，臀部再到肩背依次落下。 07、25：甩落、失手；亦可接外力反应 |
| 82.5–86.5s | 绊倒与撑地 | 重心冲到脚前，双手先撑地，再伏下停稳。 07、17、20：扑空、摔落与压住纸缝 |
| 86.5–89.5s | 接住落星 | 先追视落点，接触后手臂向下卸力，再护到身前。 01、18、32：接住朱红星 |
| 89.5–93.5s | 送回星轨 | 伸手送出，轻轻松掌，让星继续沿轨迹前行。 32、35：把星送回运行的队列 |
| 93.5–97.5s | 双手拉杆 | 先握住，再沉下重心拉动，最后松手站回。 06、22、23：连杆与升降机构 |
| 97.5–101.5s | 双手转轮 | 双手跟住轮缘，用肩背带动来回推转。 10、22、29、30、31：星环变成舵 |
| 101.5–106.5s | 抵住并推开 | 双掌贴住，压低身体蓄力，推移后收手。 13、24、30：扶纸、锁具与推动星环 |
| 106.5–110.5s | 单手悬挂 | 单手承重，腿自然垂下，双脚小幅错开随重心摆动。 20、25：抓边与按住最后一个卡扣 |
| 110.5–113.5s | 松手落地 | 松开抓点，双腿自然落下；脚掌踩稳后向前屈膝，再站直。 25、33：主动放手 |
| 113.5–117.5s | 抓握攀上一级 | 一脚抬膝踩上一级，换高抓点；支撑腿蹬起，后脚跟上。 22、23：机器台阶与爬梯 |
