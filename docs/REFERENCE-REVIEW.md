# 从复刻片段提取制作经验

挑和新片遇到同一问题的片段。例如观众赶不上公式、一个动作结束后没有时间读结果，或旁白在该连读的地方断开。记录原片出处、时间和实际看到或听到的变化，再定本片要试的改动。

| 要改进的地方 | 对照片段时看什么 | 新片怎么试 |
| --- | --- | --- |
| 节奏 | 观众何时认出对象、何时看见变化、何时能读懂结果。标出切点、重点词、动作落点和停留时间 | 同一个动作做长短两版。保留主动作和结果，比较压缩重复铺垫与缩短结果停留的影响 |
| 配音 | 连读、断句、重音和段落之间的气口。读音比较用相邻句，术语止于适用语境 | 用定稿生成带上下文的试听，先调整配音标点、语速或术语读法。措辞本身拗口时回到正文 |
| 视觉 | 对象的身份能否跟住，近景出现时是否仍知道它和全景的关系，变化前后能否同时比照 | 先打磨最难解释的一个动作。用统一的对象标记跨镜头追踪，突出变化区域，最后补必要公式和标签 |
| 音效和音乐 | 触碰、移动、落定以及安静的区别。切换原片、试作和静音来回看 | 把关键瞬态挂在画面事件上，听它与旁白是否互相遮盖。剧情动画用镜头时钟安排音乐和非人声音效 |

## 已有案例

- **MOVE 37，原片 112.16–114.40 秒。** 局部取样中，强调文字贴近唱词，棋盘在版面中持续可见。迁移到讲解片可试“图形保持在场，关键词触发一次强调”，再留出一小段给观众看结果。这个例子来自歌词视频，讲解片的观察窗口按本片数学任务来定。原片裁切和复刻工程在本地研究库与作品目录。
- **《Animation vs. Geometry》，原片 03:36–03:40。** 面积操作完成后保留角色反应及短暂停留。迁移到剧情动画可以在关键动作后试两种停留长度，比较结果能否读清、下一动作的动机是否成立。 [已有研究笔记](../writing/references/geometry-story-lessons.md)
- **《五次方程》v03 与 v04。** 「知道」内部断开、「有限次／加」间隔不足、数学数值「一」的读法和拗口组合是不同问题。复听时逐条比较，记录用户采用的措辞、读法及适用语境。「有限次／加」的修订后词时间间隔为 0.296 秒，是这一句的实测值。
- **台阶求和。** 同一区域的原片与修正试作并排比较。看翻转落定、拼合边缘和结果是否留足时间，再比较图形与公式。 [案例和本地对照文件](../examples/staircase/README.md)

## 生成本地对照页

```powershell
.\shuyu.ps1 validate compare reference.mp4 trial.mp4 --reference-at 112.16 114.4 --trial-at 3 5.8 --output output/<项目>/reports/reference/index.html
.\shuyu.ps1 listen <项目> <配音行ID> --context 1 --before <旧版源码目录>
```

对照页从各自的选段起点播放。选择原片、试作或静音，可单独拖动其中一侧检查落点。页面引用本机已有视频。配音试听页按词时间显示句间留白，播放待查句和相邻句；旧版目录可使用归档中带时钟与音频的源码副本。

试作后在作品的 `retro.json` 记录 `referenceTrials`。填写原片时间、观察、自己的改动、试作时间和证据，结果可记为 `worked`、`unclear` 或 `failed`。用 `shuyu validate retro` 校验，用 `shuyu validate summary` 回看跨片结果。若只做了抽帧或测量，把验证范围写进证据说明。 [复盘示例](retro.example.json)
