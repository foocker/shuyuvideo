# 数语视频仓库：积累方向

2026-10-30，按用户明确的方向：**先沉淀现有案例的颜色与视觉风格，再逐渐积累素材、公共能力、作品、表达方式和案例研究。**

## 基础与来源的分工

- `shuyuvideo` 现有作品是视觉身份和已有数学动画能力的来源；当前基线是 [数语暖白 v1](../style/README.md)。
- Math-To-Manim 提供可选用的数学讲解场景和制作能力，按 [片段接入约定](../math/README.md) 适配到本仓库。
- [art-motion 研究资料快照](../studies/references/art-motion/README.md) 保存实际引用的拆解、运动和声音方法及源码片段。它们是研究依据，尚未作为运行引擎接入；其风格库不自动替代数语的视觉身份。
- [完整作品研究](../studies/README.md) 在本机保存案例、原视频、字幕、抽帧和来源记录，不随 Git 分发。[创作指引](../studies/production-guide.md) 把研究方法接到新片简报和分镜；本地指引存在时，Astra 新任务保存其快照。
- [动作、镜头与转场](../motion/SKILL.md) 统一设计规范、运行时、SVG 路径审查、独立 GSAP 取帧与倒序重访；素材来源及分镜覆盖归入 [公共验证](VALIDATION.md)。[台阶案例](../examples/staircase/REVIEW.md) 记录实际验证和几何修正，出处与许可见 [来源说明](../motion/SOURCE.md)。

## 六类积累

| 类别 | 当前起点 | 何时收入公共部分 |
|---|---|---|
| 视觉风格 | `style/` 的参数、职责、样张和来源 | 在实际新片中确认一致性后更新版本 |
| 素材 | Ω 角色、已有模型和可选音效等 | 有来源、用途和必要许可说明；能独立找到并使用 |
| 公共能力 | Ω API、主题适配；几何、渲染、声音脚本候选 | 脱离原作品仍可运行，且输入、输出和适用范围明确 |
| 作品 | 人体、莫比乌斯、字形、解环、阶梯求和、《遭遇》讲解 | 本地保留各自源码、素材、说明和验证；公共能力另行提取 |
| 表达方式 | 聚焦局部、保持对象身份、映射、贡献汇总等 | 有案例支持；新题材验证与“已在原片观察到”分开记录 |
| 案例研究 | 反向传播研究，以及自己作品的复盘 | 有时间码、视听证据、解释和适用边界 |

`catalog.json` 是当前入口索引。`films/`、`studies/` 和 `output/` 仅在本地保存，远程克隆不包含对应作品、研究资料或成片；索引保留这些入口便于本机查找。已有几何项目按作品登记，不因为能渲染就宣称为任意题材可用的通用能力。来源仓库和原作者信息作为出处保留。未迁入的接入实验不登记为可用能力。

后续只有出现实际内容时才建立对应公共目录。先保持作品可重建，复用时再收拢重复实现。

## 每次新作品怎样增加积累

1. 从表达任务出发，确定对象、公式、镜头和声音职责。
2. 应用数语主题，给对象分配稳定的语义色；选择已有能力或适配外部片段。
3. 完成原型与整片检查，将数学/几何、画面、声音的验证分别记录。
4. 保存作品；把可独立复用的素材与能力登记到索引。`shuyu validate reuse` 统计公共模块被几部作品使用，两部独立作品用过才算已验证，示例不计入。
5. 将有效表达及失败原因连回案例证据；一次成功只覆盖实际完成的范围。具体做法：
   - 每次发现新缺陷，登记到 [defects.json](defects.json)，写明原因和防止再犯的检查；暂时只能人工发现的标为 `open`。`shuyu validate defects` 确认登记的检查文件存在。
   - 每部作品完成后，按 [retro.example.json](retro.example.json) 写 `films/<作品>/retro.json`：用了哪些方法（编号以本地方法库为准）、在第几秒、解决什么障碍、效果如何，遇到了哪些登记过的缺陷。`shuyu validate retro <文件>` 校验，`shuyu validate summary` 按方法汇总所有作品，作为修改 [methods.md](../studies/methods.md) 适用范围的依据。

研究的吸收分三步：保存可回看的案例证据；按理解障碍选择表达方法；在新作品中核对效果并回写适用范围。观察证据与迁移验证分开记录，不因进入索引就升级为通用规律。

当前制作与验收见 [架构](ARCHITECTURE.md)、[制作选项](PRODUCTION-OPTIONS.md) 和 [验证约定](VALIDATION.md)；具体作品范围见其 `REVIEW.md`。
