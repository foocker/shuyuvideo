# 其余技能何时接入

这份清单保留选型结论，不会自动安装、更新或调用外部项目。候选均未登记为本仓库可运行的能力。

| 技能 | 采用时机 | 接入前需要处理 |
| --- | --- | --- |
| ruler-progress-render | 数轴、迭代次数、参数刻度 | 从表达需求提炼本地组件；原技能主要是外部 Remotion 启动器 |
| 3d-chladni-render | 声学、振动、模态专题 | 固定外部源码版本；独立核对模型；预览 GIF 的 CC BY-NC 许可见来源说明 |
| threejs-earth-render | 球面路线、经纬度与地理专题 | 本地化 CDN、固定版本和画幅，适配场景时间接口 |
| light-spotlight-render | 章节标题扫光 | 清理默认品牌文案，使用本地 GSAP 和暂停时间轴 |
| wechat-2d-render | 对话式引出问题 | 替换示例头像、账号和聊天文案；适配本地时间轴 |
| remotion-candlestick | 金融与统计专题 | 作为数据绘制参考，核实数据并固定快照 |
| remotion-3d-ticker | 课程、书籍、案例封面展示 | 将时间取样适配到当前合成框架 |
| colorize | 原彩色照片的黑白到彩色揭示 | 独立 GPU 依赖；不作为黑白照片的推断上色 |
| printed-curtain-render | 布料、织物或交互演示 | 固定模拟步长与输入；处理乱序取帧；保留 CC BY-SA 及 p5.js 许可 |
| procedural-fish-render | 特定程序运动演示 | 核对外部源码、参数接口及真实复用需求 |
| fisheye-motion | 明确需要屏摄、摩尔纹和畸变的镜头 | 保护公式阅读和真实几何含义 |
| remotion-vinyl-player | 音乐展示 | 按专题选用，不纳入当前数学片默认流程 |
| claude-typer | 打字效果 | 原技能依赖作者个人网站远程合成；需要时本地实现并采用数语文案 |

本次优先吸收的另外三个技能见 [来源与许可记录](../SOURCE.md)。
