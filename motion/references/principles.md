# 面向教学的动作规范

本规范吸收程序动画中的十二原则与路径动画检查方法，来源见 [SOURCE.md](../SOURCE.md)。它服务于现有数学镜头和 Ω 角色，具体时长随口播、动作距离和观众的读取任务确定。

## 先写动作，再写缓动

用一句话写出“哪个对象，为什么动，到哪里停，观众应看到什么关系”。按需要列出准备、启动、运动、接触、停稳、读取几个阶段；为关键阶段标记时间、位置、朝向、支点和保持的关系。

准备动作应说明意图。停顿应留给观察、比较和思考。没有信息作用的等待可以删去。一个镜头只有一个主要视觉任务，角色、相机和次要标注围绕它安排。

## 十二原则如何使用

| 原则 | 在数语中的用法 | 边界 |
| --- | --- | --- |
| 挤压与拉伸 | Ω 蓄力、落地压缩、手势回弹 | 接触点固定；面积证明中的方块不因装饰而变形 |
| 预备动作 | 先看目标，再指向；移动前短暂准备 | 不给每次公式出现添加无意义延迟 |
| 清楚呈现 | 焦点区域、稳定背景、主次分明 | 关键计算时减弱角色和镜头的次要运动 |
| 关键姿态与连续动作 | 先锁定翻转前后、拼合和停稳姿态，再插值 | 插值路径不能破坏已声明的几何约束 |
| 跟随与重叠 | 身体先停，手臂稍后收住 | 次要动作不抢先，不破坏轮廓和接触 |
| 缓入缓出 | 根据距离和意图调整速度 | 不能靠同一种弹性曲线解释所有材料和动作 |
| 弧线 | 手势、关节和绕行使用合适轨迹 | 数学指定直线或测地线时服从模型 |
| 次要动作 | 目光、眨眼强化主要行为 | 不与关键结论同时争夺注意力 |
| 节奏 | 首次演示留读取时间，重复步骤可压缩 | 无固定 20:50:30 比例；以理解任务为准 |
| 夸张 | 放大指示方向、反应或局部镜头 | 不能把示意变形伪装成精确测量 |
| 稳定构造 | 保持身份、支点、体积感和遮挡关系 | 数学拓扑与连续性另有严格约束 |
| 个性与吸引力 | Ω 的动作态度、清楚轮廓和节奏对比 | 不以粒子、抖动和音效掩盖动作不清 |

## 可重复的实现

使用 `state = f(time, inputs, parameters)`；每次取样独立计算。保持小数时间，不依赖前一帧、墙上时钟或未固定种子的随机数。

动作衔接时核对位置和速度；有意的碰撞或硬切可以不连续，但应在分镜中说明。次要跟随可取主轨迹在 `time - delay` 的状态。缩放和旋转围绕明确支点，避免脚底或拼合边界滑动。

先验证对象关系和接触点，再调路径与节奏，然后加入次要动作。几何和运动应在无模糊、无粒子、无音效时仍可读。

## SVG 描边与最终姿态

优先使用已有准确矢量，把语义部件分成稳定 ID。需要描边的路径应确认起点、方向、长度归一化及线帽；自交路径可能过早显出另一分支，必要时按经过交点的顺序拆分遮罩。

拆分处分别检查前一帧、交接时刻和后一帧。圆线帽和遮罩宽度可能导致提前显露或停顿；使用截图与数值样本定位，再决定线帽、路径分段或缓动调整。不要把上游个别浏览器的经验直接当作所有版本的事实。

曲线审查同时看结构与放大图。少量平滑曲线通常比密集像素描边更容易维护；IoU 或像素重合度不能替代对端点、负形和轮廓的判断。

静态目标与动画终态应保持几何、颜色、大小、位置一致。同一时间正序、倒序和重新加载后的状态应一致。读取停顿不应被通用“持续运动”检查误判为故障。
