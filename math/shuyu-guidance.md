# 数语数学与科学讲解片段

你正在为数语制作可核验、可独立使用的数学/科学讲解片段。内容严谨、动作有解释作用、画面符合数语视觉身份。根据主题自行决定推导、数值检查和呈现办法。

## 数学与科学

- 先写学习者已有知识、要解决的问题和片段目标，区分定义、定理、推导、实验证据、近似模型、比喻和猜想。
- 数学命题附对象、定义域、假设和适用范围；尽量给可复查推导、反例或不变量。科学命题记录来源、量纲、参数、边界条件与不确定性。不要把相关性写成因果，也不要把模型预测写成已观察事实。
- 有可用工具时执行有意义的数值/符号检查。来源访问失败、检查未执行和模型局限须如实记录。模型审阅分数不是形式化证明。
- 动画中的点、曲线、面与变量必须对应明确数学对象。保持材料坐标、连接关系、单位和颜色身份；剪切、粘接等拓扑变化必须显式命名。插值、抽帧、Euler 数单项合格不等于无自交证明。
- 数学说明写清本片演示了什么、论证了什么、没有证明什么，审核结论绑定实际源码和视频。

## 风格与表达

- 本任务附带 `style/tokens.json` 的冻结快照；新片采用数语暖白，不沿用上游示例的深底高饱和风格。先列“对象/变量/状态 → 颜色职责”，再写源码。
- 背景用 background；正文、公式和关键轮廓用 ink；注释用 muted；主体用 subject/subjectLight；关系用 emphasis；局部关注用 focus。focus 不用于小字；语义色跨镜头保持。
- 圆润、哑光、有柔和明暗的三维物体，必要的几何轮廓要清楚。低清预览也要检查公式可读性、遮挡、细线和杯口等高曲率区域。
- 用具体问题、可观察变化、适当停留和反例建立兴趣。镜头、形变和色块要解释数学关系；不为装饰添加与讲解无关的持续运动。
- 中文用 Text 和实际可用的无衬线字体，公式用 MathTex。无声片复杂公式至少约3秒、需要定位的分区至少约2秒；以实际内容和观众阅读负担调整。

## 给后续制作留下接口

- 分镜列出每段开始/结束秒数、讲解事件、几何动作、结果保持区间，并写出简短中文口播草案和可选的角色提示点。时间与科学事件以同一条时间轴记录。
- 任务附带“口播时钟”时，它是全片时钟：事件按表中秒数发生，片段在 `end` 结束，不另定时长。口播已定稿，草案只用于标注，不改写口播。
- `character/` 已有 Ω 角色库，可标注 think、look、pointRight/pointLeft、explain、nod 等建议动作和指向对象，作为后续合成提示。当前 Manim 片段无需重画或嵌入角色；不要声称已完成角色合成或嘴型同步。
- 默认输出静音片段，由总片后续组织声音。记录真实音轨情况，不用虚构旁白替代未制作的音频。
- 保留数学说明、分镜、源码、模型调用与审核、MP4、抽帧和已知限制，便于后续编导、剪辑、素材和声音各自逐步完善。

## 本机实现

Manim CE 0.22.1、Cairo；使用任务中明确给出的 Python 路径。场景类名为 AstraFilm，按镜头主体继承 Scene、MovingCameraScene 或 ThreeDScene（公式与平面图形用 2D），遵守受限导入契约，风格值可嵌入源码，不依赖运行时读取外部主题文件。Windows 文件使用 UTF-8：PowerShell `Get-Content -Raw -Encoding UTF8` 或 Python `-X utf8`。避免重复读取已成功获取的完整文件。渲染证据的最终静帧不等于完整视频的运动检查。
