# 修正版时间表

按第二版 Astra 源码编排，实际编码为 108 秒、1620 帧，见 [编码核验](evidence/video-verification.json)。源运行目录的 `storyboard.json` 保留最初的 90 秒计划；本表对应根据实际画面审核进行的节奏修订。

| 时间 | 内容 |
| --- | --- |
| 0–8 秒 | 并列展示理想杯子的完整边界与环面，区分凹陷和把手隧道。 |
| 8–23 秒 | 拓扑空间与开集：空集和全空间、任意并、有限交。三条公理各停留 3 秒。 |
| 23–41 秒 | 双射、连续、逆函数连续；再单独解释集合原像。三个同胚条件各停留 3 秒。 |
| 41–59 秒 | 依次展示外壁、杯沿、内壁、内底和外底；各区域有至少 2 秒静止展示。 |
| 59–63 秒 | 杯子端点停留，辨认两个固定材料点和彩色邻域。 |
| 63–86 秒 | 23 秒连续形变：先减浅凹陷，再将杯身与把手调整为环面。 |
| 86–90 秒 | 环面端点展示。 |
| 90–96 秒 | 完整边界、一个普通把手与曲面分类定理。 |
| 96–108 秒 | 球面与环面的亏格、欧拉示性数及总结。 |

第二版保持解析映射和时间参数函数不变，改用固定对角线的三角网格，并扩大、调整紫色材料邻域。对应源码比较见 [geometry-preservation.json](evidence/geometry-preservation.json)，实际审核与历史版本保留在源运行目录的 `attempts/`、`probes/`、`renders/` 中。本版成片仍有待修订缺陷，见 [案例状态](README.md)。
