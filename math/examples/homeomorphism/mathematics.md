# 数学说明

统一采用完整杯面模型，给出可直接实现的周期参数化、分阶段杯子→环面形变、解析可逆性依据和实际数值检查；外部参考资料因网络限制未核验。

对象与定义

全片统一比较完整边界曲面。杯子具有厚度、一个完整普通把手，无裂缝、额外密闭空腔或退化接触；表面包括内外壁、杯沿连接区、内底与外底。空气能进入杯口，但完整表面在杯沿处没有边界。轮胎仅表示理想实心环形体的边界。两者均取 ℝ³ 的子空间拓扑，不讨论真实轮胎结构。

拓扑空间 (X,τ) 满足：∅,X∈τ；任意族开集的并仍在 τ；有限个开集的交仍在 τ。τ 中元素叫开集。拓扑描述邻近与连续，不指定长度、角度、体积。

f:X→Y 连续，意为每个 V∈τY 都满足 f⁻¹(V)∈τX，其中 f⁻¹(V)={x∈X:f(x)∈V} 是集合原像，对任何函数都有定义。同胚另要求 f 双射、f 连续、逆函数 f⁻¹:Y→X 连续。将原像定义与逆函数条件分镜呈现。一般拓扑空间无需嵌入三维；橡皮式运动只是此例的直观帮助。

可实现的共享曲面

采用圆润厚壁杯的几何示意，避免拼接独立杯身与把手。以下公式直接给出一个闭合周期曲面，整个过程保留参数点身份。

参数域为 Q=(ℝ/2πℤ)²，u,v∈[0,2π)，时间 t∈[0,1]。两方向端点均识别；软件中的重复接缝顶点代表同一点。

初始径向函数：
A(u)=cos²u/4+sin²u/2.56，B(u)=0.6cos u；
ro(u)=[−B+√(B²+2.56A)]/(2A)；
ri(u)=[cos²u/0.45²+sin²u/0.85²]⁻¹ᐟ²；
b₀(u)=0.18+0.46(1−cos u)。

它们对应 xz 平面内的外椭圆 (x+0.3)²/4+z²/2.56=1，以及把手洞的内椭圆 (x−0.9)²/0.45²+z²/0.85²=1。左侧厚、右侧细，形成杯身与把手。

定义 H(s)：s≤0 时为 0，0<s<1 时为 3s²−2s³，s≥1 时为 1。
a(t)=0.68[1−H(t/0.4)]，λ(t)=H((t−0.4)/0.6)。

令
ro,t=(1−λ)ro+1.95λ；ri,t=(1−λ)ri+1.05λ；
bt=(1−λ)b₀+0.45λ；ct=0.9(1−λ)；
mt=(ro,t+ri,t)/2，dt=(ro,t−ri,t)/2，ρ=mt+dt cos v。

先取 Pₜ(u,v)=(ct+ρcos u, bt sin v, ρsin u)。再施加凹陷变换：
qₐ(x,y)=1−a exp(−[(x+1)²+y²]/0.36)，
Wₐ(x,y,z)=(x,y,−1.7+qₐ(x,y)(z+1.7))。
最终曲面 Fₜ=Wₐ₍ₜ₎∘Pₜ。

t=0 是带圆润杯沿、深凹杯口、厚底和完整侧把手的示意杯。凹陷来自表面向下弯曲，没有挖去网格或添加封口。前 40% 的运动仅减浅凹陷，后 60% 调整杯身和把手比例。

t=1 精确得到竖直环面：
F₁(u,v)=((1.5+0.45cos v)cos u, 0.45sin v, (1.5+0.45cos v)sin u)，
满足 (√(x²+z²)−1.5)²+y²=0.45²。

为何这条路径可用

内椭圆严格位于外椭圆内部，因为其任一点满足外椭圆表达式≤1.65²/4+0.85²/2.56=0.9628515625<1。因此 ro>ri>0；插值后仍成立，且 bt>0。

对固定 t，Pₜ 的 xz 投影相对中心 (ct,0) 的极角唯一确定 u；随后径向坐标和 y 唯一确定截面椭圆上的 v。故它在周期商空间 Q 上单射。

qₐ≥0.32，det DWₐ=qₐ>0；其逆变换为 z=(z′+1.7)/qₐ−1.7，x,y 不变。因此凹陷变换不会合并材料点。完整反解依次为：撤销 Wₐ；用 atan2(z,x−ct) 得 u；用 atan2(y/bt,(ρ−mt)/dt) 得 v。

Fₜ 连续且单射，Q 紧致、ℝ³ Hausdorff，所以 Fₜ 是到其像的同胚。具体杯面到环面的对应为 F₁∘F₀⁻¹。这个论证支持所列精确数学模型；离散三角网格、插值实现和实际成片仍须审查，不能由采样结果宣布整段动画绝无自交。

若需说明厚度，将截面边界椭圆填成椭圆盘，即 ρ=mt+dt r cos v、y=bt r sin v，0≤r≤1，再施加 Wₐ。得到实体 D²×S¹；影片比较的始终是它的边界。

截面、材料点与数值

y=0 的截面由 Fₜ(u,0) 与 Fₜ(u,π) 两条闭曲线组成。后者围出把手隧道，可用金色强调；它不等于杯口凹陷。不要另加不随参数运动的装饰洞口。

杯子在 x=−1,y=0 处，上表面 z≈−0.676384，下表面 z≈−1.635616，材料厚度约 0.959232，凹陷没有穿透杯底。撤销凹陷后对应高度为 ±1.498800。

可固定材料点 (u,v)=(π,3π/2)：位置从约 (−0.925,−1.100,−0.03949) 到 (−1.500,−0.450,0)。另一点 (0,3π/2) 从约 (1.525,−0.180,0) 到 (1.500,−0.450,0)。点和颜色全程不变。

小邻域使用固定参数开矩形 |u−u₀|<0.12、|v−v₀|<0.16 的像。着色面积与轮廓一起随 Fₜ 更新；可见边线仅帮助识别，不表示开集包含边界。

独立拓扑依据与反例

普通无把手厚壁杯的材料拓扑是三维球；沿两个互不相交的边界圆盘附加一个普通实体把手，得到一个亏格一把手体。其边界等于从球面去掉两个开圆盘，再沿两条边界圆接入圆柱侧面。这里的分解用于数学分析，不在形变中演出撕裂或粘接。

球面 χ=2；去掉两个圆盘使 χ 减少 2；接入圆柱侧面不再改变 χ，故杯面 χ=0、g=1。闭合连通可定向曲面分类定理说明它同胚于 S¹×S¹。“闭合”在此指紧致且无边界。

结束比较：球面 g=0、χ=2；环面 g=1、χ=0。欧拉示性数是同胚不变量，因此二者不可能同胚。χ=2−2g 及亏格分类仅在上述曲面类别内使用。“洞数相同”不是任意拓扑空间的完整判据；同伦等价也不等于同胚。抽象同胚不自动推出指定三维嵌入之间存在环境同痕。

90 秒教学安排

沿用七段：0–8 秒形状提问；8–19 秒拓扑；19–34 秒同胚与原像；34–43 秒完整杯面；43–74 秒核心形变，其中两端各停留 4 秒、连续运动 23 秒；74–80 秒说明几何示意与独立论证；80–90 秒球面反例。

正文保留“示意”标记。建议相机 θ≈−75°、φ≈55° 同时展示杯口与把手，杯口近景可到 φ≈30°。实测 API 支持所需 Surface 和 ThreeDScene 相机方法。公式只用 MathTex，中文用 Microsoft YaHei；数学参数细节进入制作说明，不全部上屏。
