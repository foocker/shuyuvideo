# 把作品研究用于数语新片

本指引用于教学简报和分镜阶段，来源是本仓库的 [七种表达方法](methods.md) 与
[反向传播案例](cases/backpropagation/README.md)。这些方法只有单案例支持，
应按当前主题选用；它们不能替代数学论证，也不要求采用原片的画风。

先写观众已有认识、当前卡住的问题和希望新增的认识，再决定哪种画面操作能解释它。

| 方法 | 何时考虑 | 分镜需要写清 |
|---|---|---|
| M01 同一对象返回 | 新概念容易打断对象追踪 | 对象身份保持什么；再次出现时多理解了什么 |
| M02 缩小再恢复范围 | 因素过多，局部关系看不清 | 暂时固定或省略的条件；何时恢复；能否推广 |
| M03 局部变化与影响 | 要比较变量的影响大小 | 控制变量、变化量和结果共用计算模型；局部结论的范围 |
| M04 保留来源再汇总 | 多条路径或多个因素共同作用 | 每项来源、方向、单位，以及求和、平均或加权的具体运算 |
| M05 多种表示对应 | 图、公式与表格难以联系 | 同一个量在各视图的符号和颜色对应；避免用形似暗示等价 |
| M06 基准与近似 | 需要解释数值方法或简化模型 | 相同输入下的基准、近似、收益和误差；区分示意与计算结果 |
| M07 收束与边界 | 局部都懂却难以复述整体 | 用已建立含义的对象收束；把限制放在比喻或结论附近 |

按需要选择零至三种方法，不必凑齐七种或固定次序。分镜简要记录：
方法编号、要解决的理解障碍、具体镜头动作、应保持的数学关系、结果读取时间。
若不适用，说明原因即可。颜色服从数语语义色，缓动只改变呈现时间，不改变数学关系。

成片后分别检查数学正确性、对象可追踪性和实际阅读节奏，记录失败与修正。
只有新作品的证据支持时，才更新方法的适用范围；观众学习效果仍需单独验证。
声音尚未制作时，不把字幕间隔当成已验证的静默或节拍。
