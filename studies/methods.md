# 从完整作品提取的表达方法

目前只有一个作品案例。以下 7 项均为**单案例支持的迁移假设**；画面存在的证据、对创作作用的解释、在新题材中的效果是三个不同层次。还没有跨作品验证或观众理解测试。

方法可以组合，但顺序不固定。优先根据“观众卡在哪里”检索，而不是根据想要哪一种视觉风格检索。

| 观众的障碍 | 候选方法 |
|---|---|
| 对象太多，忘了当前在讲什么 | M01、M02 |
| 知道有关联，但不知道为什么影响不同 | M03 |
| 看懂单条关系，无法理解多个关系怎样共同作用 | M04 |
| 图看懂了，公式或表格仍然陌生 | M05 |
| 不理解实际算法为什么偏离理想算法 | M06 |
| 每步都看过，却无法复述整体或分清边界 | M07 |

## M01 · 同一个对象带着新含义返回

**问题：** 新概念不断加入时，观众容易重新寻找对象和背景。

**操作：** 选一个足以承载主要关系的核心对象。首次出现用于建立问题；局部解释后返回，让它显示新理解；总结时再将局部变化接回整体。每次返回都写清“比上次多看懂什么”。

**必须保留：** 对象身份和关键关系。颜色、布局和尺度可以随表达需要变化，但变化不能使对象失去可追踪性。

**证据：** [E02](cases/backpropagation/index.html#E02) 保留数字 2 的实例身份；[E12](cases/backpropagation/index.html#E12) 回到已出现的梯度向量；[E14](cases/backpropagation/index.html#E14) 用熟悉图像回顾整体。

**迁移提案：** 讲曲面分类时让同一个曲面先作为“形状”，再显示切割关系，最后标记已获得的不变量；每个阶段必须明确何种变化被允许。该提案尚无动画验证。

**失败条件：** 仅重复素材，未增加关系；每次回来参数和命名无故变化；早期的示意对象被后期误当成真实数据。

**实现候选：** 稳定对象 ID、跨段状态、可见子集和强调状态。先在新作品上验证，再决定是否提炼统一接口。

## M02 · 缩小问题，再逐层恢复范围

**问题：** 观众同时面对太多因素，无法看到最小的解释关系。

**操作：** 明确暂时固定或忽略什么，保留一个实例和局部依赖；解释清楚后，依次恢复被省略的关系。范围变化需要可见提示和语言条件。

**证据：** [E04](cases/backpropagation/index.html#E04) 留下一个输出的依赖；[E08](cases/backpropagation/index.html#E08) 向上一层提出要求；[E10](cases/backpropagation/index.html#E10) 重复到更前一层；[E11](cases/backpropagation/index.html#E11) 恢复样本维度。

**迁移提案：** 讲图上的流量，先固定一个节点解释流入流出，再加入相邻节点，最后检查全网约束。需要确认局部规则确实足以支持全局结论。

**失败条件：** 局部结论无法推广却未经说明直接推广；切换例子导致条件改变；通过淡出删除了决定结论的边界条件。

**实现候选：** 依赖子图、对象保留与恢复、范围标签。取景是表现方式之一，也可以用显隐、布局或高亮完成。

## M03 · 用局部变化解释影响大小

**问题：** 观众知道变量相关，却不知道哪一个更有影响、为什么。

**操作：** 明确比较口径，保持其他相关条件可比；指认变量，展示小幅变化及结果，再对另一变量进行同量级比较。可用亮度、大小、数值和公式共同编码。

**证据：** [E01](cases/backpropagation/index.html#E01) 比较梯度分量 3.2 与 0.1；[E03](cases/backpropagation/index.html#E03) 比较输出偏离目标的程度；[E06](cases/backpropagation/index.html#E06) 对应上游激活与权重影响。

**迁移提案：** 讲杠杆时固定力臂或力，分别改变另一个量，并把力矩读数接到同一计算模型。该提案尚未制作。

**失败条件：** 同时改变多个因素却只归因于一个；把局部导数当成任意有限变化的比例；使用装饰性数值而未满足公式。

**实现候选：** 共享数值模型、受控参数扰动、结果同步显示。动画缓动只决定呈现时间，不应改变数学关系。

## M04 · 保留来源，再汇总贡献

**问题：** 看懂单个因素的作用后，观众不理解多条路径或多个样本怎样合成。

**操作：** 先显示单个来源，再引入其他来源；为贡献保留方向、相对量及归属；说明汇总运算，最后把汇总结果用于下一步。

**证据：** [E09](cases/backpropagation/index.html#E09) 多个输出的贡献；[E10](cases/backpropagation/index.html#E10) 汇总后继续传播；[E11–E12](cases/backpropagation/index.html#E11) 多个样本逐参数平均。

**必须区分：** 网络依赖路径上的求和，与数据集维度上的平均。相似的多列画面不意味着同一种计算。

**迁移提案：** 讲合力时先保留每个力的来源和向量，再形成合力；讲期望时保留概率权重。不能把向量求和、标量平均、概率加权混成一个无语义的“聚合动画”。

**失败条件：** 未解释为何合并；来源在汇总前消失；方向抵消没有表现；将需求标记画成已经执行的参数更新。

**实现候选：** 带来源和单位的贡献对象、显式运算类型、分组汇总、结果追踪。

## M05 · 同一量在图、公式、表之间对应

**问题：** 观众把不同表达形式当成互不相干的新知识。

**操作：** 为同一对象建立一一对应的符号和图形标识；切换表示时保留身份，再强调原位置与新位置的关系。可以移动或形变，也可以并排对应。

**证据：** [E05](cases/backpropagation/index.html#E05) 网络与激活公式；[E06](cases/backpropagation/index.html#E06) 连线与乘积项；[E12](cases/backpropagation/index.html#E12) 参数所在表格行与梯度向量分量。

**迁移提案：** 在线性代数中，把同一个向量在几何图、坐标列和线性组合中的表示保持关联；改变基底时明确坐标变了而几何向量未变。

**失败条件：** 同色却不同义；以外形相似暗示数学等价；图形变形改变了本应保留的关系；只配符号，没有指明其所指。

**实现候选：** 语义对象到多种视图的映射、公式 token ID、对应高亮。通用点列形变可作为底层手段，不能替代数学对应。

## M06 · 先建立基准，再解释实际近似

**问题：** 实际算法的技巧看起来像凭空增加的规则。

**操作：** 先解释理想方法及目标，再指出其成本，展示一个近似方案，同时保留收益与代价。比较使用相同任务与评价口径。

**证据：** [E13](cases/backpropagation/index.html#E13) 在全体样本平均之后引入小批量；用两条下降轨迹解释估计误差与计算速度的取舍。

**迁移提案：** 讲数值积分时先建立面积定义，再说明精确计算的困难，比较不同分块精度的近似。示意图与真实误差结果分开标明。

**失败条件：** 只展示速度优势，隐藏误差；把示意路径当作测量结果；将经验性有效说成无条件保证。

**实现候选：** 两种方案共享输入、同步比较进度与结果、明确示意和计算数据。

## M07 · 局部理解后收束，并说明边界

**问题：** 观众看懂了片段，却未形成整体过程，或把比喻当作事实。

**操作：** 在已有局部关系上给出便于记忆的说法，并就近注明限制；全片末尾用已经建立含义的对象串回流程；说明后续还缺哪种知识或条件。

**证据：** [E07](cases/backpropagation/index.html#E07) 神经科学类比及限定；[E14](cases/backpropagation/index.html#E14) 回顾训练流程；11:27–12:27 接续微积分、实现和标注数据。

**迁移提案：** 讲完一个几何操作后，让观众用同一图复述步骤，并明确操作成立的条件。语言间隔、画面归并和结果停留分别安排；当前案例不提供统一停顿秒数。

**失败条件：** 总结时再加入大量新概念；只重播画面而没有重新组织关系；免责声明太迟才出现；用字幕句间间隔代替真实听辨。

**实现候选：** 段落语义标记、动作完成时刻、结果保持区间、口播提示点。应允许声音和画面错开，而非强制逐句一一对应。

## 在新作品中怎样验证

每次选用一条方法，记录预期解决的理解障碍、实际画面、失败现象及修改后的结果。首先检查关系和数值是否正确、对象是否能追踪；再用正常速度检查信息能否读完、声音是否帮助当前操作。

只有新题材的实现和审阅支持其效果时，才把状态升级为“跨题材验证”。观众是否更理解，仍需单独的复述或任务测试。当前七项全部停留在单案例支持阶段。
