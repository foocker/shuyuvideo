# art-motion 研究资料快照

这里保存 [能力比较](../../art-motion-reuse.md) 实际引用的 15 份文档和源码，
可在本仓库内阅读。它们用于核对研究结论，尚未作为数语的运行引擎接入。

来源：[alchaincyf/huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion)。
固定提交、上游路径和 SHA-256 见 [sources.json](sources.json)，许可见 [LICENSE](LICENSE)。

文件内容按原字节保存，并加上 `.txt` 后缀，便于将源码片段作为文本查阅。
其中提及的导入模块、素材和上游文档路径属于原始实现背景；本研究的阅读页和
证据重建不执行这些片段，也不需要完整上游仓库。需要实现某项能力时，先根据
新作品明确需求，再把所需代码、依赖和验证一并收入数语。
